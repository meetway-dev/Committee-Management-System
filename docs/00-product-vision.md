# BachatZone (CMS)

## Product Vision

BachatZone is a modern Progressive Web Application (PWA) that digitizes traditional committee savings (ROSCA/Chit Fund) management.

The application replaces manual tracking using WhatsApp groups, Excel sheets, notebooks, and paper records with a secure, transparent, and user-friendly platform.

The goal is to make committee management simple, trustworthy, and accessible for everyone, regardless of technical experience.

The application should feel like a modern banking application while remaining extremely easy to use.

---

# Problem Statement

Millions of people participate in savings committees.

Today these committees are managed using:

- WhatsApp groups
- Phone calls
- Excel spreadsheets
- Paper notebooks
- Manual calculations

These methods create many problems.

Examples include:

- Forgotten payments
- Late payments
- Payment disputes
- Missing records
- No payment history
- Difficulty tracking turns
- Difficulty managing large committees
- No automatic reminders
- No transparency

The platform should solve these problems.

---

# Solution

Provide one centralized platform where committee organizers and members can manage every aspect of their committee.

Users should be able to:

- Create committees
- Invite members
- Track payments
- Manage payout turns
- View payment history
- Generate reports
- Receive reminders
- Keep permanent records

Everything should happen in one application.

# Development Principles

Every new feature should answer these questions:

1. Does this make committee management easier?
2. Does this improve trust?
3. Does this improve transparency?
4. Does this improve the user experience?
5. Is the feature scalable?
6. Is the feature secure?
7. Does it work well on mobile?
8. Is it simple enough for non-technical users?

If the answer is "No" to most of these questions, reconsider the feature before implementing it.
