# BachatZone

## Project Name

BachatZone

## Project Type

Progressive Web Application (PWA)

## Goal

Build a modern web application that helps users create, manage and participate in savings committees (ROSCA / Chit Fund).

The application should replace manual tracking through WhatsApp, notebooks and Excel sheets.

The application must work like a native mobile application while also being fully usable on desktop browsers.

Users should be able to install the application directly from the browser.

## Target Countries

Pakistan

India

Bangladesh

UAE

Saudi Arabia

Africa

Any country where committee savings are common.

## Main Objectives

Easy committee management

Secure authentication

Payment tracking

Member management

Turn scheduling

Reports

Notifications

Responsive UI

Scalable architecture
