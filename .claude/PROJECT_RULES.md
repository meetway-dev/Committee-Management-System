# Business Rules

A user can create unlimited committees.

The creator automatically becomes the Committee Admin.

Only the Committee Admin can edit committee settings.

Members cannot edit committee rules.

A committee cannot start until the minimum required members have joined.

Every payment must belong to exactly one committee.

Every payout belongs to exactly one member.

Payments require admin approval.

Members may upload payment screenshots.

Payment history can never be deleted.

Committee history can never be deleted.

Completed committees should be archived instead of deleted.

Every important action should create an Activity Log.

A member can belong to multiple committees.

Each committee has its own members, payments and payout schedule.

Committee Admin can transfer ownership to another member.

Admin cannot leave the committee until ownership is transferred.

Late payments should be tracked.

Every member should always know:

- Total Paid
- Remaining Amount
- Next Payment
- Turn Number
- Payout Status
