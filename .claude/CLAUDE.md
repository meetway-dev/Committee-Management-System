Installable

- Next.js (Latest)

## Coding Rules

Always use TypeScript.

Always use App Router.

Use Server Components whenever possible.

Use Client Components only when necessary.

Keep components reusable.

Do not duplicate logic.

Follow SOLID principles.

Never rewrite unrelated files.

Never rename folders unless requested.

Always explain your implementation plan before coding.

Always use existing project structure.

Prefer reusable hooks.

Prefer reusable services.

Use Tailwind CSS only.

Use Shadcn UI components.

Never use inline CSS.

Keep functions small.

Write production-ready code.

Use proper error handling.

Use loading states.

Use empty states.

Use skeleton loaders.

Use toast notifications.

Do not install unnecessary packages.

If something is unclear, ask first.

Never generate placeholder code.
